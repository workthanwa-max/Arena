# 🧠 AI Skills & Architecture Guidelines

ยินดีต้อนรับสู่โฟลเดอร์ **SKILLS** 
โฟลเดอร์นี้ถูกสร้างขึ้นมาเพื่อเปรียบเสมือน "สมองส่วนกลาง" และ "กฎกติกา" ของโปรเจกต์นี้

## 🎯 จุดประสงค์ของโฟลเดอร์นี้
เราใช้โฟลเดอร์นี้เพื่อเก็บไฟล์ Markdown (`.md`) ที่ทำหน้าที่เป็น **Custom Instructions (คำสั่งเฉพาะเจาะจง)** หรือ **Skill Files (ทักษะของ AI)** สำหรับให้ AI เข้ามาอ่านเพื่อทำความเข้าใจสถาปัตยกรรม กฎการเขียนโค้ด และมาตรฐานการออกแบบของโปรเจกต์ *ก่อนที่จะเริ่มสร้างงานจริง*

การมีโฟลเดอร์นี้ช่วยให้:
1. **ไม่ต้องสั่งงานซ้ำ (Zero Repetition):** AI จะรู้ทันทีว่าต้องใช้ Tech Stack อะไร โครงสร้างโฟลเดอร์เป็นแบบไหน โดยดึงจาก "ค่าเริ่มต้น (Default Configuration)" ในแต่ละไฟล์
2. **รักษามาตรฐานของโค้ด (Consistency):** ไม่ว่าคุณจะเริ่มแชทใหม่ (New Session) กี่ครั้ง โค้ดที่เจนออกมาก็จะยังคงเป็นไปตามสถาปัตยกรรมระดับองค์กร (เช่น Modular Monolith, Role-Isolated Client)
3. **ลดข้อผิดพลาด (Error Reduction):** AI จะปฏิบัติตามมาตรฐาน Security และ UI Design ที่ตั้งไว้อย่างเคร่งครัดตามกฎวิศวกรรม
