# PulseArena — 2.5D MOBA Multiplayer Sandbox & Go Server

เซิร์ฟเวอร์ประมวลผลเกมแบบ **Server-Authoritative Multiplayer** ด้วย Go Standard Library + WebSocket (RFC 6455) + PostgreSQL สำหรับเกมเบราว์เซอร์แบบ Real-Time 2.5D MOBA บน React + Phaser พร้อม Docker Compose ครบ 3 เซอร์วิส (`postgres`, `backend`, `frontend`)

## โครงสร้างหลัก
- **`database/`**: PostgreSQL DDL Migrations (`001_init.sql`, `002_auth_modes_maps.sql`, `003_admin_heroes.sql` สำหรับ `users` (+`role`), `user_characters`, `user_sessions` (Session ไม่จำกัดอายุจนกว่าจะกด Logout), `rooms` รหัส 6 หลัก, `room_players`, `game_records`)
- **`go-backend/`**: Go Backend Server (Port `7777` HTTP/WS + Port `8443/udp+tcp` HTTP/3 WebTransport QUIC) — ระบบ Dual-Channel Real-Time Transport (**WebTransport QUIC Unreliable Datagrams + Reliable Control Stream** พร้อม Automatic Fallback ไปยัง **Compact Binary WebSocket `?proto=bin1`** รองรับ EffectKinds ถึง 510 ชนิด ลดขนาด Packet ระหว่างเล่นจาก ~2–3 KB JSON เหลือ ~150–300 Bytes), `GET /api/transport/info`, ระบบสมาชิก Argon2id Auth + Admin Seed + Unlimited Cookie/Bearer Session, ห้องรหัสตัวเลข **6 หลัก**, **ทุกโหมด (ICONIC 1v1, 1v1, 3v3, ฝึกซ้อม Dummy) ยกเว้นตะลุมบอน FFA 5 คน ต้องเข้าห้องรอก่อนกดเริ่มพร้อมกัน**, **ฮีโร่ 51 ตัว** (50 สาธารณะ incl. **Aizen, Toriko, Frieren, Gray Fullbuster, Diavolo, Cid Kagenou/Shadow, Thai Ghosts [Pop, Speed Grandma, Krahang, Krasue], Kung Fu Panda [Po, Tai Lung, Kai], Marvel [Gambit, Iron Man], One Piece [Trafalgar Law, Garp], Tansan, Sun Wukong, Nezha, King, Gon, Steve, Doraemon, Yami, Seven Deadly Sins [Escanor, Meliodas], Record of Ragnarok [Adam, Beelzebub, Buddha], CJ Palony** + แอดมินลับ **หลวงพี่ศร/ไซตามะ**), Tick Loop `60 Hz` และ `pgx/v5` Connection Pool
- **`Example-Game/`**: PulseArena Frontend (Nginx Port `5555`) — เอนจินสมรภูมิหลัก **Three.js 3D มุมกล้อง MLBB Tilted Isometric** พร้อมโมเดลตัวละคร 3D ทั้ง **51 ตัว** หมุน 360° ตามทิศทางจริง (รวมร่างแปลง 9 หาง `naruto` และ Hogyoku Wing Evolution `aizen`, `steve`, `doraemon`, `po`, `krasue`, `krahang` ฯลฯ) + **Client-Side Movement Prediction & Smooth Server Reconciliation (`Mlbb3dArenaView.tsx`)** + **RealtimeTransport (`realtimeTransport.ts` + `realtimeProtocol.ts`)** + **Match-Scoped Asset Preloader (`assetPreloader.ts`)** + **4-Step User Journey** + เสียงพากย์อนิเมะ/ไทย/อังกฤษ (`edge-tts` MP3 ครบทั้ง 51 ฮีโร่) + React 19 + TypeScript + Three.js + Zustand + GSAP + Local SQLite WASM (`cache_v11`)
- **`docker-compose.yml`**: รัน `postgres` (Port `5435`), `backend` (Port `7777` + `8443/udp+tcp`), และ `frontend` (Nginx Port `5555` พร้อม Reverse Proxy `/api/` + `/ws` และ Gzip) ร่วมกันใน Network เดียว
