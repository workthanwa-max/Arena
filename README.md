# PulseArena — 2.5D MOBA Multiplayer Sandbox & Go Server

เซิร์ฟเวอร์ประมวลผลเกมแบบ **Server-Authoritative Multiplayer** ด้วย Go Standard Library + WebSocket (RFC 6455) + PostgreSQL สำหรับเกมเบราว์เซอร์แบบ Real-Time 2.5D MOBA บน React + Phaser พร้อม Docker Compose ครบ 3 เซอร์วิส (`postgres`, `backend`, `frontend`)

## โครงสร้างหลัก
- **`database/`**: PostgreSQL DDL Migrations (`001_init.sql`, `002_auth_modes_maps.sql`, `003_admin_heroes.sql` สำหรับ `users` (+`role`), `user_characters`, `user_sessions` (Session ไม่จำกัดอายุจนกว่าจะกด Logout), `rooms` รหัส 6 หลัก, `room_players`, `game_records`)
- **`go-backend/`**: Go Backend Server (Port `7777` HTTP/WS + Port `8443/udp+tcp` HTTP/3 WebTransport QUIC) — ระบบ Dual-Channel Real-Time Transport (**WebTransport QUIC Unreliable Datagrams + Reliable Control Stream** พร้อม Automatic Fallback ไปยัง **Compact Binary WebSocket `?proto=bin1`** ลดขนาด Packet ระหว่างเล่นจาก ~2–3 KB JSON เหลือ ~150–300 Bytes ด้วย `NetID` & `EffectKinds` Table และตัด Head-of-Line Blocking สำหรับตำแหน่ง/การเดิน), `GET /api/transport/info`, ระบบสมาชิก Argon2id Auth + Admin Seed + Unlimited Cookie/Bearer Session, ห้องรหัสตัวเลข **6 หลัก**, **ทุกโหมด (ICONIC 1v1, 1v1, 3v3, ฝึกซ้อม Dummy) ยกเว้นตะลุมบอน FFA 5 คน ต้องเข้าห้องรอก่อนกดเริ่มพร้อมกัน**, โหมด **ICONIC 1v1 (Gojo vs Sukuna สุ่มตัวอัตโนมัติ • ไสยเวทย้อนกลับทุก 5 วิ • กางอาณาเขตชนกัน • อาณาเขตโกโจมีดาเมจ)**, **1v1 (ครบ 2 คนเริ่ม • ชนะที่ 5 Kills)**, **FFA 5 คน (เข้าเล่นทันที)**, **3v3 (ครบ 6 คนค่อยเริ่ม • ชนะที่ 50 Kills)** และ **ฝึกซ้อม Dummy (`practice`)**, คูลดาวน์เกิดใหม่ **7 วินาทีทุกโหมด**, เลือกแผนที่ (**ชิบูย่า** / **หมู่บ้านโคโนฮะ นารุโตะ**), ฮีโร่ 13 ตัว (รวม **ธนอส / `noone` 5 มณี 5 สกิล — เกิดมณีสุ่ม 1 เม็ด • +1 มณีต่อ 1 คิล • ตายแล้วมณีหายต้องสะสมใหม่ • ครบ 5 เม็ดดีดนิ้วชนะทันทีใน 3v3 หรือล้างสนามแล้วเกิดใหม่ในตะลุมบอน FFA**, **โก้/เซ็นอิซึ สายพุ่ง Dash + อัลติปาดดาว 5 แฉกตามลำดับเหมือนมูราด**, แอดมิน **หลวงพี่ศร/ไซตามะ** และ **เสี่ยม่อน/โกะโจ**), แก้จบคูลดาวน์ `0.1s` ทันที, Tick Loop `60 Hz` และ `pgx/v5` Connection Pool
- **`Example-Game/`**: PulseArena Frontend (Nginx Port `5555`) — เอนจินสมรภูมิหลัก **Three.js 3D มุมกล้อง MLBB Tilted Isometric** พร้อมโมเดลตัวละคร 3D ทั้ง 13 ตัวหมุน 360° ตามทิศทางจริง + **Client-Side Movement Prediction & Smooth Server Reconciliation (`Mlbb3dArenaView.tsx`)** ตอบสนองการเดิน 0ms + **RealtimeTransport (`realtimeTransport.ts` + `realtimeProtocol.ts`)** เลือกเชื่อม WebTransport HTTP/3 / Binary WS อัตโนมัติ + **ระบบ Match-Scoped Asset Preloader (`assetPreloader.ts`) & Browser Cache API (`pulsearena-match-assets-v1`)** โหลดเฉพาะแผนที่/ตัวละคร/สกิล/เสียงของแมตช์ให้ครบ 100% ก่อนเข้าสนามพร้อมการ์ด Matchup, Flow การเข้าสู่สมรภูมิแบบ **4-Step User Journey** (`AuthPage` → `HomePage` → `BattleSetupPage` → `RoomLobbyPage` → `Arena` + `HeroesPage`), โหมด ICONIC 3D ชิบูย่า (`IconicArenaView`), เสียงพากย์ต้นฉบับอนิเมะ (`edge-tts` MP3), React 19 + TypeScript 7 + Three.js + Zustand + GSAP + Local SQLite WASM (`cache_v11`)
- **`docker-compose.yml`**: รัน `postgres` (Port `5435`), `backend` (Port `7777` + `8443/udp+tcp`), และ `frontend` (Nginx Port `5555` พร้อม Reverse Proxy `/api/` + `/ws` และ Gzip) ร่วมกันใน Network เดียว
